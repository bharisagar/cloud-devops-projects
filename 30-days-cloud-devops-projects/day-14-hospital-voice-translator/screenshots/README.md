# Day 14 Screenshots

Use this folder to store evidence for the hospital voice translation assistant.

## Recommended Evidence

Capture screenshots of:

1. Local validation passing.
2. The app translating Kannada to English, Tamil, and Telugu.
3. Text-to-speech controls for all three target languages.
4. Urgent symptom highlighting for chest pain or breathing difficulty.
5. GitHub Actions CI/CD workflow success.
6. GitHub Pages deployment URL.

## Safe Screenshot Rules

- Do not use real patient names, phone numbers, IDs, photos, or medical records.
- Use only sample phrases from `translation-pack.json`.
- Do not show hospital internal URLs or private systems.
