# Day 13 Screenshots

Use this folder to store evidence for the local RAG DevOps runbook assistant.

## Recommended Evidence

Capture screenshots of:

1. The passing runbook assistant command.
2. The generated Markdown response with citations.
3. The dashboard showing retrieved runbook chunks.
4. The vague incident producing `needs_human_review`.
5. Your short explanation of how retrieval improves incident response.

## Safe Screenshot Rules

- Do not capture real customer incidents, secrets, access keys, or private URLs.
- Use the sample local incidents for public portfolio screenshots.
- Keep screenshots focused on retrieved citations, answer quality, and verification steps.
